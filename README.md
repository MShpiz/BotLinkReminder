# Телеграм бот который присылает уведомления об изменениях в репозиториях и ответах на StackOverflow
## Почему так мало коммитов?
Данная работа была выполнена в рамках прохождения 2х частей курса [Академия-Backend](https://education.tbank.ru/academy/backend/) от Т-Банка.
Код в данном репозитории - копия кода из закрытого репозитория, полученного для обучения на курсе.
## Описание проекта
Данное приложение разделено на 2 микросервиса, взаимодействующие через брокер сообщений Kafka или Rest API.
1. Микросервис бот - отвечает за взаимодействие с API телеграма (подписка на уведомления об изменениях статуса ответа или репозитория)
2. Микросервис скреппер - отвечает за периодическую проверку хранимых ссылок в соответствии с Rest API GitHub и StackOverflow
